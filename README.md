## 📖 项目简介

awesome-llm-apps 是一个收录了 100+ 个开源 AI 智能体(AI Agents)、Agent 技能(Agent Skills)和 RAG 应用的精选清单。每个模板都经过完整的端到端测试,采用 Apache-2.0 许可证,可自由克隆、改造甚至商用。项目兼容 Claude、Gemini、GPT、DeepSeek、Llama、Qwen 等主流开源与闭源模型,从单文件入门脚本到多智能体团队、语音智能体、生成式 UI 一应俱全。

## ✨ 主要特性

- **100+ 精选模板**:涵盖入门级智能体、进阶单/多智能体应用、常驻后台智能体等十余个分类
- **Agent 技能(Agent Skills)**:一条命令即可为 Claude Code、Codex、Cursor 等编码智能体安装新能力,每个技能都附带真实代码并通过安全与评测 CI 门禁
- **多智能体协作团队**:金融分析、法律研究、招聘筛选、游戏设计等跨领域多智能体团队开箱即用
- **语音 AI 智能体**:基于实时语音 API 的语音进/语音出应用,包括客服、保险理赔等场景
- **RAG 全家桶**:从最简 RAG 链到 Agentic RAG、纠错式 RAG、知识图谱 RAG、多模态 RAG 等 20+ 种检索增强方案
- **生成式 UI 与智能前端**:智能体直接渲染交互式表单、卡片、图表和可编辑面板
- **MCP 生态集成**:通过 Model Context Protocol 连接浏览器、GitHub、Notion 等外部工具与数据源
- **模型无关**:同时适配 Claude、Gemini、GPT、DeepSeek、Llama、Qwen 等模型,多个模板支持完全本地运行
- **免费开源**:Apache-2.0 许可证,克隆即用,可商用
